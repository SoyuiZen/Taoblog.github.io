你好，欢迎来到我的博客 👋

这是本站在 2026 年 10 月 30 日发布的第一篇文章。从今天起，我会在这里记录三类内容：

- **技术笔记**：开发中踩过的坑、学到的新工具，用文字把它们固化下来
- **读书摘记**：读过的书里，值得留下来的句子与想法
- **随想碎片**：生活里一闪而过的念头

## 为什么是静态网站

这个网站由纯 HTML、CSS 和 JavaScript 构成，托管在 GitHub Pages 上。它没有服务器、没有数据库，因此：

1. **快**：打开就是全部，没有加载等待
2. **稳**：不依赖任何付费服务，几乎不会被攻击
3. **省**：完全免费，唯一的花销是一个域名（可选）
4. **久**：所有文章都是 Markdown 纯文本，十年后依然可读

> 写作是最好的思考。把想法写下来，模糊才会变得清晰。

## 发布一篇文章有多简单

写好后只需三条命令：

```bash
git add .
git commit -m "新文章：你好，世界"
git push
```

一分钟之内，全世界都能看到它。
