这篇文章分享我每天在用的写作流程。工具全部免费，流程可以在任何设备上复制。

## 总览

整个流程只有三步：

![写作流程图](img/workflow.svg)

## 第一步：捕捉灵感

灵感是易碎品，出现后十分钟内就会消失。我的做法是：

- 手机备忘录随手记下关键词，只写一句话
- 每周末花 10 分钟整理，把值得写的挑出来
- 一个想法超过三次出现在脑海里，就值得动笔

## 第二步：用 Markdown 成文

写作我使用 VS Code + Markdown，理由很简单：

| 优点 | 说明 |
| --- | --- |
| 纯文本 | 任何设备都能打开，永不担心格式丢失 |
| 专注 | 没有排版干扰，写作时只面对文字 |
| 可迁移 | 换平台、换主题，内容原封不动 |

常用语法只有几个：`#` 标题、`-` 列表、`**加粗**`、`> 引用`、`` `代码` ``。

## 第三步：git push 发布

```bash
git add posts/新文章.md
git commit -m "新文章：我的写作工作流"
git push
```

推送后托管平台会自动重新发布，大约一分钟生效。

## 一些原则

1. **先完成，再完美**：初稿允许很烂，好文章是改出来的
2. **固定时间写作**：把写作放进日程，而不是等灵感
3. **长短不限**：300 字的想法也有价值

希望这套流程对你有用。
